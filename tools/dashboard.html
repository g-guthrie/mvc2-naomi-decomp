What this measures

Matching means the compiled source bytes equal the original. Linked means those same bytes also occupy the correct original address in the linked ELF. Raw data, assembly, and copied image bytes earn no source credit. The complete rebuilt image can match retail while source reconstruction is still at the beginning.

Current scope: main SH-4 program. The service/test executable, additional code in other ROMs, graphics, and audio are separate work. This is not yet a native port or a fully source-built game.
