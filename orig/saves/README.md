# Dreamcast VMU saves

Save data for the **Dreamcast** port of Marvel vs. Capcom 2 (US, `T1212N`).
Not used by the NAOMI decomp build — kept here only for testing the game under Flycast.

| File | Contents |
|---|---|
| `mvc2-dc-vmu-all-unlocked.bin` | 128 KB VMU image, one file `MVLVSCP2_SYS` (5 blocks, dated 1999-11-27) |

To use: copy to `~/Library/Application Support/Flycast/data/vmu_save_A1.bin`
(back up the existing file first).

sha256 of `mvc2-dc-vmu-all-unlocked.bin`:
`a64c19ba813f53ffdb78a1a1e907bde12916e9f6765a798a0a3196acb885f8d8`
